# World Flags Game

Welcome to the World Flags Game! This is a fun and interactive web game where players guess the country based on the displayed flag.

- [Usage](#usage)
- [Game Rules](#game-rules)

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/world-flags-game.git
   ```
2. Navigate to the project directory:
   ```
   cd world-flags-game
   ```
3. Install the dependencies:
   ```
   npm install
   ```

## Usage

To start the game, open the `public/index.html` file in your web browser. You can also run a local server for a better experience.

## Game Rules

1. A flag will be displayed on the screen.
2. You have to guess the country that the flag belongs to.
3. Points are awarded for each correct guess.
4. The game continues until you decide to stop.
